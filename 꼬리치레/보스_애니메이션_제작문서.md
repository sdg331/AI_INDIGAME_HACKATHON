주의
- 이동 행의 영역을 y 630부터 잡으면 「이동 모션」 라벨 글자가 이동1에 섞인다. **y 640 이상**으로 자른다(시험에서 확인).
- 공격 · 스킬 프레임은 궤적 · 고리가 몸과 겹친다. 자동 절단은 몸+이펙트가 한 덩어리로 나오므로 **몸만 남기는 손질**이 필요하다(5절).
- 스킬 프레임은 고리가 머리 위까지 올라가 몸 높이 자동 검출이 틀린다. 발바닥(약 y 1160)과 머리 꼭대기(약 y 985)를 손으로 잡아 몸 높이 약 175로 본다.
- 축소율이 행마다 다르다(4방향 0.19 · 이동 0.40 · 아래 행 0.34). 픽셀 격자가 원본에서 일정하지 않다는 뜻이므로 **정수 배율 축소는 불가능**하다. 「몸 높이 60」으로 통일해 리샘플한다.

## 2. 규격과 기준점

| 항목 | 값 | 비고 |
|---|---|---|
| 몸 높이 | 60px | 머리 꼭대기(뿔 제외)~발바닥. 뿔 끝은 62~64px까지 올라갈 수 있다 |
| 발바닥 | 캔버스 **y = 62** | 주인공 시트와 같다. 아래 1px 여유 |
| 머리 중앙 x | 캔버스 중앙(64 캔버스 x 32, 80 캔버스 x 40, 96 캔버스 x 48) | 몸통이 좌우로 흔들리는 프레임도 **발 위치**를 고정하고 머리는 따라가게 |
| 가슴 중앙 | 64 캔버스 기준 대략 (32, 30) | A3가 실제 값을 README에 적는다. A4 피격 · 그로기 이펙트 정렬점 |
| 손끝(이펙트 발생점) | 공격 프레임의 뻗은 손 끝 | 80 캔버스 기준 A3가 실측해 README에. A4 하트 참격 · 하트 탄 정렬점 |
| 넓은 캔버스 배치 | 80×64는 64×64를 x+8 · y+0에, 96×80은 x+16 · y+16에 놓은 것과 같다 | 주인공 규약과 동일. 발바닥은 80 캔버스에서도 y62, 96×80에서는 y78 |
| 팔레트 | `보스문서_바르갈.md` 1.4의 12색 | 양자화 뒤 색이 13개 이상이면 잘못된 것 |
| 투명 | 배경 알파 0. 반투명 없음 | 축소 뒤 마스크를 127 기준으로 이진화 |
| 방향 | 오른쪽 보기 | 게임에서 왼쪽은 반전 |

## 3. 절단 → 64px 파이프라인

부록 스크립트가 1~6을 한다. 7은 손이다.

1. **영역 자르기** — 1절의 「영역」으로 자른다. 라벨 · 구분선이 들어오지 않게 여유를 좁게.
2. **배경 마스크** — 배경 `#000101`과의 색 차이(RGB 합) 60 초과를 그림으로 본다. 드레스 최암부 `#281F2B`는 차이 약 90이라 남는다.
3. **그림자 제거** — 아래에서 위로 행을 훑어 채도(최대−최소 채널)가 25 이하인 회색 행이 이어지는 구간을 그림자로 보고 잘라낸다. 부츠 바닥이 회색이면 같이 잘릴 수 있으니 결과에서 발바닥이 평평한지 본다.
4. **축소** — 몸 높이가 60이 되도록 LANCZOS 리샘플. 폭은 비율대로. 마스크도 같은 배율로.
5. **양자화** — 12색 팔레트로 디더 없이. 그 뒤 마스크 127 기준 이진화로 알파를 만든다.
6. **배치** — 캔버스 폭 중앙, 발바닥 y62. 넓은 캔버스는 2절 오프셋.
7. **손질** — 5절.

시험 4장(대기 · 이동1 · 정면 · 공격)의 결과: 얼굴 · 뿔 · 머리카락 · 드레스가 64에서 읽힌다. 눈은 2px 폭으로 남는다. 이동1은 라벨이 섞였고(영역 y 조정으로 해결), 공격은 궤적이 잘렸다(80 캔버스 + 이펙트 분리로 해결).

## 4. 프레임 매핑 — 애니메이션별 제작표

「출처」는 1절의 프레임 이름. 「만드는 법」: **절단** = 시트에서 잘라 정리 · **반전** = 좌우 반전 · **수정** = 절단본에서 일부 픽셀만 고침 · **신규** = 새로 그림(절단본을 밑그림으로). 프레임 시간은 플머.

### 4.1 대기 — 64×64 × 4 (루프)
| # | 출처 | 만드는 법 | 내용 |
|---|---|---|---|
| 1 | 대기 | 절단 | 기본 자세. 대기 프레임은 정면에 가까운 3/4 각도라 횡스크롤에서 어색하면 **우측**(4방향) 프레임을 대신 쓴다. 둘을 나란히 놓고 정한다 |
| 2 | 1 | 수정 | 몸통 1px 위로(들숨). 머리카락 끝 1px 안쪽 |
| 3 | 1 | 그대로 | 복귀 |
| 4 | 1 | 수정 | 몸통 1px 아래(날숨). 꼬리 끝 1px 위로 |

### 4.2 걷기 — 64×64 × 8 (루프)
| # | 출처 | 만드는 법 | 내용 |
|---|---|---|---|
| 1~8 | 이동1~8 | 절단 + **반전** | 시트 순서 그대로. 발 접지 위치가 프레임마다 흔들리면 발바닥 y62에 다시 맞춘다 |
시트의 8장이 실제로 8단계 보행인지 확인한다. 같은 포즈가 반복되면 6장으로 줄이고 README에 적는다.

| # | 출처 | 만드는 법 | 내용 |
|---|---|---|---|
| 1 | 달리기 | 절단 | 시트의 달리기 = 접지 프레임 |
| 2 | 1 | 수정 | 앞다리 접지 → 뒷다리 들림, 머리카락 1px 더 뒤로 |

| 1~3 | 마력 고리 1 | 수정. 양손을 옆으로 벌린다(모음과 구분). 3장은 점점 더 넓게 |
| 4~6 | 마력 고리 4 | 그대로 ×3. 고리 3회(A4가 반지름을 키운다). 몸은 같은 프레임, 머리카락만 1px씩 더 떠오름 |
| 7~8 | 6 | 신규. 양손을 머리 위로 |
| 9 | 8 | 수정. 폭발 순간, 몸 1px 위, 머리카락 최대 |
| 10~12 | 마력 고리 6~8 | 그대로. 후딜 |

### 4.12 그로기 — 64×64 × (4 + 1)
| # | 출처 | 만드는 법 |
|---|---|---|
| 1 | 피격 2 | 그대로. 움찔 |
| 2 | 1 | 수정. 뒤로 반 걸음, 양팔 늘어짐 |
| 3 | 2 | 수정. 앞으로 1px 기울며 비틀거림 |
| 4 | 3 | 수정. 다시 서며 고개 숙임 |
| 5 | 4 | 수정. **멈춤 포즈.** 고개 숙임 · 눈 감음 · 양팔 늘어짐 · 꼬리 바닥. 이 프레임에서 정지 |
색 변화 · 무릎 · 호흡 루프는 근접 유닛(A2) README를 따른다(확정). A2가 나오기 전에는 위 그대로.

### 4.13 여유 시
- **2페이즈 대기 ×4** — 대기 1~4에서 머리카락 · 꼬리 끝 1~2px 떠오름, 눈 밝은 분홍.
- **등장 ×6** — 후면(절단) → 후면·좌측 중간(신규) → 좌측(절단, 반전해 오른쪽 보기) → 우측 대기 3장. 등을 보이고 있다가 돌아선다.
- **물러서며 하트 탄 ×8** — 하트 탄 재활용, 1~3에 뒤로 뛰는 도약 프레임(달리기 3 반전).
- **하트 비 ×8** — 마력 고리 1~3(한 손만 위로) + 후딜.

### 4.14 작업량
| 구분 | 프레임 수 |
|---|---|
| 절단만 | 14 (4방향 4 · 이동 8 · 대기 · 달리기 접지) + 공격 · 피격 · 스킬 몸만 3 = **17** |
| 수정 | 약 45 |
| 신규 | 약 10 (달리기 도약 · 예고 팔 동작 · 양손 머리 위 등) |
| 필수 시트 합계 | 대기 4 · 걷기 8 · 달리기 6 · 하트 참격 9 · 이단 참격 11 · 하트 탄 9 · 피격 3 · 전환 8 · 고리 8 · 돌진 9 · 폭주 12 · 그로기 5 = **92프레임**, 그중 고유 프레임은 약 40 |

순서: 대기 → 걷기 → 피격 → 하트 참격 → 그로기 → 달리기 → 마력 고리 → 페이즈 전환 → 하트 탄 → 이단 참격 → 돌진 참격 → 마력 폭주 → 여유 항목. 대기 · 걷기 · 하트 참격 · 그로기가 나오면 플머가 보스전 뼈대를 붙일 수 있다.

## 5. 손질 규칙

절단본에 반드시 하는 것
1. **윤곽 1px** — 리샘플로 생긴 2px 두께 윤곽을 1px로. 팔레트 최암부 `#281F2B`.
2. **눈** — 2×2px 이상으로 또렷하게. 눈 색 `#96567B`, 하이라이트 1px `#FCE8DF`. 예고 프레임은 `#E7A1AC`.
3. **뿔 끝 · 귀 끝 · 꼬리 끝** — 1px로 뾰족하게 살린다. 리샘플에서 뭉개진다.
4. **하트 장식** — 가슴 · 버클 · 꼬리 끝의 하트는 3×3px 안에서 하트로 읽히게. 안 되면 점 하나로 두고 README에 적는다.
5. **반투명 제거** — 알파 0 또는 255만.
6. **색 수 확인** — 12색 + 알파. 피격 1의 흰 플래시만 예외.
7. **발바닥 y62** — 모든 프레임에서 발바닥 가장 아래 픽셀이 y62.

반전본에 하는 것
- **꼬리** — 반전하면 꼬리가 몸 앞으로 온다. 지우고 몸 뒤(왼쪽)에 다시 그린다.
- **머리 가르마 · 더듬머리** — 원본 방향으로 되돌린다.
- **하트 버클** — 대칭이라 그대로.

## 부록 — 절단 스크립트 (파이썬, Pillow · numpy)

`보스2.png`와 같은 폴더에서 실행한다. `outputs/보스_바르갈_v1/원본프레임/`에 프레임별 64×64(공격 80×64, 스킬 96×80) PNG와 4배 확대 확인용 시트를 만든다. 손질 전 단계까지만이다. 시험 4장은 이 코드로 뽑았다.

```python
# 보스 시트 절단 — 손질 전 단계. 실행: python 보스_절단.py
from PIL import Image
import numpy as np, os

SRC = '보스2.png'
OUT = 'outputs/보스_바르갈_v1/원본프레임'
os.makedirs(OUT, exist_ok=True)

# 이름: (영역 x0,y0,x1,y1, 캔버스 폭, 캔버스 높이, 반전 여부)
REGIONS = {
    '정면':  (300, 90, 540, 450, 64, 64, False),
    '후면':  (560, 90, 790, 450, 64, 64, False),
    '좌측':  (810, 90, 1020, 450, 64, 64, True),   # 왼쪽 보기 → 반전
    '우측':  (1040, 90, 1240, 450, 64, 64, False),
    '이동1': (40, 640, 190, 820, 64, 64, True),
    '이동2': (190, 640, 340, 820, 64, 64, True),
    '이동3': (340, 640, 490, 820, 64, 64, True),
    '이동4': (490, 640, 640, 820, 64, 64, True),
    '이동5': (640, 640, 790, 820, 64, 64, True),
    '이동6': (790, 640, 940, 820, 64, 64, True),
    '이동7': (940, 640, 1090, 820, 64, 64, True),
    '이동8': (1090, 640, 1240, 820, 64, 64, True),
    '대기':  (40, 945, 200, 1180, 64, 64, False),
    '달리기': (240, 945, 440, 1180, 64, 64, False),
    '공격':  (455, 945, 700, 1180, 80, 64, False),  # 궤적 포함, 손질 필요
    '피격':  (730, 945, 920, 1180, 64, 64, False),
    '스킬':  (940, 940, 1245, 1180, 96, 80, False), # 고리 포함, 몸 높이 손으로
}
PALETTE = [(0xFC,0xE8,0xDF),(0xF6,0xCF,0xC5),(0xE7,0xA1,0xAC),(0x6D,0x32,0x5B),
           (0xEA,0xD7,0xD5),(0xBD,0x96,0xA4),(0x96,0x56,0x7B),(0x28,0x1F,0x2B),
           (0x61,0x31,0x53),(0x4D,0x32,0x45),(0x2F,0x22,0x30),(0x43,0x2B,0x36)]
BODY_H = 60      # 몸 높이
FOOT_Y = 62      # 64 캔버스에서 발바닥 y (넓은 캔버스는 오프셋 적용)

im = Image.open(SRC).convert('RGB')
a = np.asarray(im).astype(int)
bg = a[600, 20]                                     # 배경색 샘플
mask = np.abs(a - bg).sum(axis=2) > 60

pal = Image.new('P', (1, 1))
pal.putpalette(list(sum(PALETTE, ())) + [0, 0, 0] * (256 - len(PALETTE)))

def bbox(x0, y0, x1, y1):
    ys, xs = np.where(mask[y0:y1, x0:x1])
    return x0 + xs.min(), y0 + ys.min(), x0 + xs.max() + 1, y0 + ys.max() + 1

def shadow_top(b):
    """아래에서 위로 훑어 채도 낮은 회색 그림자 구간을 건너뛴 y를 돌려준다."""
    x0, y0, x1, y1 = b
    for y in range(y1 - 1, y0, -1):
        m = mask[y, x0:x1]
        if m.sum() == 0:
            continue
        px = a[y, x0:x1][m]
        if (px.max(axis=1) - px.min(axis=1)).mean() > 25:
            return y + 1
    return y1

preview = []
for name, (x0, y0, x1, y1, cw, ch, flip) in REGIONS.items():
    b = bbox(x0, y0, x1, y1)
    st = shadow_top(b)
    bx0, by0, bx1, _ = b
    body = im.crop((bx0, by0, bx1, st))
    m = Image.fromarray((mask[by0:st, bx0:bx1] * 255).astype('uint8'))
    scale = BODY_H / (st - by0)
    w = max(1, round(body.width * scale))
    small = body.resize((w, BODY_H), Image.LANCZOS)
    m = m.resize((w, BODY_H), Image.LANCZOS).point(lambda v: 255 if v > 127 else 0)
    q = small.quantize(palette=pal, dither=Image.NONE).convert('RGBA')
    q.putalpha(m)
    if flip:
        q = q.transpose(Image.FLIP_LEFT_RIGHT)
    canvas = Image.new('RGBA', (cw, ch), (0, 0, 0, 0))
    ox = (cw - w) // 2
    oy = (FOOT_Y + (ch - 64)) - BODY_H          # 발바닥 = y62 (+캔버스 세로 오프셋)
    canvas.paste(q, (ox, oy), q)
    canvas.save(f'{OUT}/{name}_{cw}x{ch}.png')
    preview.append(canvas.resize((cw * 4, ch * 4), Image.NEAREST))
    print(f'{name}: bbox={b} shadow_top={st} body_h={st - by0} scale={scale:.3f} flip={flip}')

# 확인용 4배 시트
W = sum(p.width for p in preview); H = max(p.height for p in preview)
sheet = Image.new('RGBA', (W, H), (40, 40, 40, 255)); x = 0
for p in preview:
    sheet.paste(p, (x, H - p.height), p); x += p.width
sheet.save(f'{OUT}/_확인용_4배.png')
```

스크립트가 못 하는 것: 궤적 · 고리 분리(공격 · 스킬), 스킬 프레임의 몸 높이(고리 때문에 자동 검출이 틀린다 → `REGIONS['스킬']`의 y0을 985로 좁혀 다시 돌리거나 손으로), 반전본의 꼬리 위치, 그리고 5절의 손질 전부.
