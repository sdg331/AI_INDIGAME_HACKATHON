# 적 · 스켈레톤 v1 — 스프라이트 시트

원본: 사용자가 넣어 준 `적 1.png`(1254×1254 AI 생성 캐릭터 시트, Skeleton). 시트의 이동 8프레임 · 대기 · 공격 · 피격 셀을 잘라 64px 밀도로 내리고, 부족한 프레임(예고 · 스미어 · 플래시 · 그로기)은 기존 포즈를 이동 · 기울임 · 스케일 · 색 변환으로 합성했다.
**직접 그린 프레임은 없다.** 원본 시트에 있는 포즈만 재조합했다.

## 임포트 규약 (주인공과 동일)

- **Pivot = Bottom Center.** 발바닥 선 y=62(0부터). 80 캔버스도 x=40이 몸 중심.
- **Pixels Per Unit은 주인공과 같은 값.** 캔버스만 넓고 밀도는 같다.
- 방향: **오른쪽을 본다.** 왼쫓은 엔진에서 X 반전.
- 대기 포즈 키 58px(주인공 60px). 폭 46px. 시트 전체 24색 공통 팔레트, 안티에일리어싱 없음, 투명 배경.
- 앵커 x는 원본 시트의 바닥 그림자 타원 중심을 썼다. 포즈가 바뀌어도 발 위치가 튀지 않는다.

## 프레임 순서와 의미

### 대기 (4)
1 기본 → 2 몸 1px 위로 늘림(들숨) → 3 유지 → 4 기본. 루프.

### 이동 (6)
원본 이동 모션 1·2·3·4를 쓰고 4→3→2로 되돌아오는 핑퐁. 원본 5~8프레임은 방패가 등 뒤로 넘어가 있어(AI 시트의 좌우 불일치) **쓰지 않았다.** 홀수 프레임에서 몸 1px 들림.

### 공격 (10) — 예고 5장
| # | 구간 | 동작 |
|---|---|---|
| 1 | 서기 | 대기 포즈 |
| 2 | 예고 | 뒤로 2px, 상체 2px 뒤로 기울임 |
| 3 | 예고 | **최대 백스윙** — 뒤로 4px, 3% 웅크림, 상체 4px 뒤로 |
| 4 | 예고 | 홀드 |
| 5 | 예고 | 홀드, 1px 떨림 |
| 6 | 휘두름 | 스미어 — 원본 공격 포즈를 가로 12% 늘림, 상체 앞으로 |
| 7 | 휘두름 | **접촉** — 원본 공격 포즈, 앞으로 4px |
| 8 | 휘두름 | 홀드 |
| 9 | 회수 | 공격 포즈 가로 4% 줄임, 앞으로 1px |
| 10 | 서기 | 대기 포즈 |

- 원본 공격 셀은 방패가 왼쪽(등 뒤), 검을 앞으로 내지른 자세다. 대기 포즈(방패 앞)에서 넘어갈 때 방패 위치가 바뀐다. 6프레임 스미어가 그 튐을 가린다.
- 히트박스 참고: 접촉 프레임(7) 칼날은 캔버스 오른쫓 끝 부근(x 60~78, y 30~40).
- 패리 판정 시간은 플머가 정한다. 3·4·5는 같은 포즈라 홀드 길이를 늘려도 어색하지 않다.

### 피격 (4)
1 **플래시**(실루엣 `#FFF1E6`, 외곽 `#D8C8C0`) → 2 뒤로 3px + 상체 젖힘 → 3 뒤로 1px → 4 대기.
원본 피격 셀은 검을 놓친 듯 손을 벌린 포즈다. 머리 주변 충격선은 원본에 있던 것.

### 그로기 (6) — 「멈춘다」
1 앞으로 쏠림 → 2 뒤로 젖힘 → 3 5% 가라앉음 → **4 멈춤**(7% 가라앉음, 상체 앞으로, 명도 82%) → 5 유지 → 6 유지(8%). 4~6 루프. 완전 정지가 필요하면 4만 홀드.
쓰러지지 않는다. 눈이 꺼지는 표현은 원본에 눈 픽셀이 검정이라 넣지 않았다.

## 알려진 한계

1. **발 밑 얇은 회색 잔여.** 원본의 바닥 그림자 타원 중 뼈와 같은 톤인 부분은 지우지 못했다. 발 아래 1px 정도. 지면에 닿은 음영처럼 보이나, 완벽히 지우려면 손질 필요.
2. **이동이 핑퐁.** 진짜 걷기 사이클(한 발 → 통과 → 반대 발)이 아니라 1~4를 왕복한다. 원본 시트 5~8이 좌우 불일치라 대체가 없었다.
3. **공격 예고는 상체 기울임과 이동으로만 표현.** 무기를 치켜올리는 실제 백스윙 포즈는 원본에 없다.
4. 색이 회백색 단일 톤이라 A2 세션의 「마족 = 보라 회색 + 주황 눈」 팔레트와 다르다. 세계관의 「피부가 단단한 마족」과 스켈레톤이 맞는지는 팀이 정한다.
