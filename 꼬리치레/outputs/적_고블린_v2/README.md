# 적 · 고블린 v2.3 — 스프라이트 시트 (작업 ID E2)

**v2.3 (공격 접촉 포즈 재추출).** 공격 5~9번(스미어 · 접촉 · 홀드 · 팔로우스루 · 회수)은 v1 시트를 물려받았는데, 이 포즈는 흉부 정도가 아니라 **몸통 · 조끼 · 뒷다리 대부분이 지워진 상태**였다(머리 · 귀 · 팔 조각 · 다리 조각만 남음 — 같은 배경 키잉 문제). 대기 포즈처럼 메꿔서 될 양이 아니라 `_생성스크립트/gob_attack_src.py`가 원본 `적 2.png` 「공격」 셀을 **다시 잘라냈다**: 참격 호(밝은 저채도 큰 덩어리, 6px 넓힘 · 칼날 보호)와 바닥 그림자를 먼저 배경 취급 → 가장자리와 이어진 명도 < 14 영역만 배경(v1은 < 48) → 뒷발 발목 상자만 문턱값 3(원본에서 발목이 명도 0~30의 검은 외곽선뿐이라 v1부터 발이 떠 있었다) → 조끼 픽셀(턱 밑 상자의 어둡고 채도 낮은 픽셀)을 대기 조끼와 같은 갈색 E 평균으로 옮김 → v1과 같은 배율로 축소 → 24색 스냅. 스미어 · 회수 변형 값은 v1과 동일, 위치만 2px 왼쪽(칼끝이 캔버스 밖으로 나가지 않게).

**v2.1 (흉부 보정).** v1부터 대기 포즈의 **가슴~배가 투명하게 뚫려 있었다.** 원본 `적 2.png`에서 고블린은 어깨끈 아래에 거의 검은 가죽 조끼를 입는데, v1의 배경 키잉(명도 < 48 = 배경)이 조끼를 배경으로 보고 지운 것이다. 영향 프레임은 대기 포즈를 쓰는 **대기 4장 · 피격 4번 · 공격 0~4번 · 10번**(이동 상체 · 공격 접촉 · 그로기는 다른 셀이라 멀쩡). `_생성스크립트/gob_chest.py`가 조끼를 다시 그려 채웠다(147px). **v2.2: 색을 갈색 가죽으로.** v2.1은 원본대로 검은 조끼(M/N/L)였으나 어두운 배경에서 여전히 빈 것처럼 읽혀, 허리천 · 부츠와 같은 갈색 5색으로 바꿨다 — E `#75513C` 면 · D `#81553D` 왼쪽 림 라이트 · G `#694635` 턱 그림자 · J `#5B3E30` 팔 밑 그림자 · M `#372B21` 외곽선. 어깨끈(K/L/M)은 그 위에 어두운 띠로 남는다. 새 색 0개. 어깨끈 · 주머니 · 벨트 · 팔은 원래 픽셀 그대로 위에 남는다. 같은 김에 **대기 · 피격의 다리 사이 배경 구멍도 지웠다**(아래 질문 7 해소) — 공격 서기 프레임과 같은 처리라 대기 → 공격 전환에서 튀지 않는다.

v1(`outputs/적_고블린_v1/`)의 「알려진 한계」 4건을 고친 판. 입력은 **v1 시트의 픽셀 배열**이며 numpy로 직접 편집했다(외부 이미지 생성기 사용 없음). v1 폴더는 읽기만 했다.
