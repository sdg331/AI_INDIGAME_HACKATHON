# 적 · 스켈레톤 v2 — 스프라이트 시트

v1(`outputs/적_스켈레톤_v1/`, 원본 포즈 재조합만)의 「알려진 한계」 4건을 고친 판. 원본은 `적 1.png`(사용자 제공 AI 캐릭터 시트). 스켈레톤 디자인(검 · 방패 · 비율)은 바꾸지 않았다.
새 프레임은 전부 **v1 파이프라인이 만든 64px 프레임의 픽셀 배열을 numpy 로 파츠(머리 · 몸통 · 뒤다리 · 앞다리 · 검+손)로 나눠 이동 · 회전 · 압축 · 재합성**해 만들었다. 외부 이미지 생성기는 쓰지 않았고, 팔레트는 v1 `_build.json` 24색 그대로다(새 색 0 — 빌드 시 전 프레임 검사). 손 도트 붓질은 없다 — 파츠 편집 + 픽셀 정리다.

## 규격 (v1과 동일)
- 64×64, 키 58px, **Pivot = Bottom Center**, 발바닥 y=62. 공격만 80×64(x=40 이 몸 중심).
- 오른쪽 보기. 주인공과 같은 Pixels Per Unit. 24색, 안티에일리어싱 없음, 투명 배경.
- **얼굴 방향(v2c).** 원본 대기 · 걷기 · 피격 셀은 3/4 뷰인데 두개골이 화면 **왼쪽**을 보게 그려져 있어 오른쪽 공격과 어긋났다. 몸(방패 앞)은 그대로 두고 **두개골(0~19행)만 좌우 반전**해 모든 시트가 오른쪽을 보게 했다(`v2tools.face_right`). 원본 「우측」 셀은 크기(101px)와 뷰가 달라 쓰지 않았다.
- 대기 발 위치: 뒤발 x 22~29, 앞발 x 33~41(y=62 기준). 이동 접지 프레임도 같다.

## 직접 만든 프레임 — 15장
이동 3 · 6 / 공격 2~9 (8장) / 그로기 3 · 4 · 5 · 6 (이동 2 · 5 는 접지의 1px 변형이라 세지 않음). 공격은 1 · 10(대기)도 검 팔을 다시 그린 것이라 원본 대기와 1~2px 다르다.

## 프레임 순서와 의미

### 대기 (4) — v1 그대로
1 기본 → 2 · 3 몸 1px 늘림(들숨) → 4 기본.

### 이동 (6) — 걷기 순환
원본 이동 1(양발 벌린 접지)과 4(뒷발 뒤꿈치 든 통과)의 **다리만** 떼어 쓰고, 상체는 원본 1로 고정했다.

| # | 단계 | 내용 |
|---|---|---|
| 1 | 접지 A | 원본 1 다리. 방패 팔 기본 위치 |
| 2 | 눌림 | 다리 1px 모음, 몸 1px 내려감 |
| 3 | 통과 A | **새 프레임.** 앞다리는 몸 아래로 딛고(바닥까지 늘림), 뒷다리는 엉덩이에 붙인 채 3px 들림. 몸 1px 올라감(머리 바운스), 방패 팔 1px 앞 |
| 4 | 접지 B | 원본 1 다리이되 **겹침 순서를 바꿔**(앞다리가 뒤로) 반대발 접지로 읽히게 |
| 5 | 눌림 | 2와 같되 겹침 순서 B |
| 6 | 통과 B | **새 프레임.** 원본 4의 딛는 다리를 뒤로, 든 다리를 앞으로 옮겨 **앞발 들림.** 몸 1px 올라감 |

- 상체 고정, 다리 접지/눌림/통과, 방패 팔 ±1px, 머리 1px 바운스 — 주인공 걷기 v4 방식. 방패는 항상 앞(오른쪽).
- 접지 A/B 의 다리 그림은 같다(겹침 순서만 다름). 실루엣 차이는 통과 프레임의 든 발이 만든다. → 감점 항목.

### 공격 (10) — 머리 위 내려치기, 예고 5장

**만든 방법.** 원본 찌르기 셀(방패가 반대쪽 · 키 49px)은 대기와 몸이 달라 5→6 에서 튀었다. v2b 는 찌르기 셀을 **쓰지 않고**, 대기 몸에서 검 팔(x<14, y 6~37)을 지운 뒤 어깨(15,19)를 축으로 **2마디 뼈 팔(어깨 → 팔꿈치 → 손)을 팔레트 색으로 다시 그리고**, 원본 검 블롭을 손 축으로 회전해 붙였다. 10프레임이 한 몸이라 튀지 않는다.
참고한 구조: 픽셀 아트 검 공격의 정석 — 예비 동작(검을 뒤로, 상체 뒤로, 방패 앞으로 균형) → 휘두름 1~2프레임(스미어는 여기만) → 접촉 홀드 → 회수. 예비 동작에서 몸을 8% 웅크려(스쿼시) 캔버스 위 여유를 만들고, 휘두름에서 3% 늘린다(스트레치).

| # | 구간 | 동작 |
|---|---|---|
| 1 | 서기 | 대기(검 팔 다시 그림) |
| 2 | 예고 | 팔을 뒤로 들어올림(손이 어깨 높이 뒤), 검 25° 뒤로, 상체 2px 뒤 |
| 3 | 예고 | **최대 백스윙** — 손이 머리 옆 위(어깨 기준 −6, −12), 검이 머리 뒤 위로 50° 젖혀짐, 몸 8% 웅크림, 상체 3px 뒤. 실루엣: 머리 위로 솟은 칼날 |
| 4 | 예고 | 3 홀드 |
| 5 | 예고 | 3 홀드 + 검 1px · 3° 떨림 |
| 6 | 휘두름 | 검이 머리 위를 지나 앞으로(100°), 뒤따르는 잔상 2장(60° · 80°, 어두운 뼈색) = **스미어**. 몸 3% 늘림, 상체 3px 앞, 앞발 2px 앞 |
| 7 | 휘두름 | **접촉** — 45° 내려침(140°). 앞발 4px 앞, 뒷발 1px 뒤, 상체 5px 앞, 몸 4% 압축 |
| 8 | 팔로우스루 | 검이 방패 옆으로 거의 수직(165°), 칼끝 바닥 근처 |
| 9 | 회수 | 검을 다시 들어올리는 중(60°), 상체 1px 앞 |
| 10 | 서기 | 1과 동일 |

- 히트박스 참고(접촉 7): 칼날 x **54~74**, y **31~45** (캔버스 좌표, 피벗 x=40 기준 오른쪽 13~34px). 칼끝이 주인공 가슴 높이(y≈43)에 온다. 팔로우스루(8) 칼날 x 53~62, y 33~57.
- 패리 판정 시간은 플머. 3 · 4 · 5 는 같은 포즈라 홀드 길이를 늘리거나 줄여도 어색하지 않다. 참고 자료 기준으로는 예비 동작을 길게(프레임당 80~100ms 이상, 최대 백스윙 홀드 길게), 휘두름 6→7 은 짧게, 접촉 7 은 길게 잡는 편이 「곧 친다 → 쳤다」로 읽힌다.
- 원본 시트의 찌르기 셀은 쓰지 않았다. 필요하면 별도 「찌르기」 시트로 살릴 수 있다(질문 5).

### 피격 (4) — v1 그대로
1 플래시(`#FFF1E6` / 외곽 `#D8C8C0`) → 2 뒤로 3px + 상체 젖힘 → 3 뒤로 1px → 4 대기.

### 그로기 (6) — 「멈춘다」
| # | 구간 | 동작 |
|---|---|---|
| 1 | 진입 | 피격 포즈, 앞으로 쏠림(v1) |
| 2 | 진입 | 피격 포즈, 뒤로 젖힘(v1) |
| 3 | 진입 | **새 프레임.** 대기 포즈에서 다리 15% 압축, 고개 1px 숙임, 검이 내려가는 중(107°) |
| 4 | **멈춤** | **새 프레임.** 다리 30% 압축(무릎 굽힘), 고개 2px 숙임, 검을 등 뒤로 늘어뜨려 **칼끝이 땅(y=62)에 닿음**, 상체 2px 앞, 명도 82%(팔레트 안으로 재양자화) |
| 5 | 유지 | 4 |
| 6 | 유지 | 4 + 고개 1px 더, 다리 2% 더(미세 호흡) |

- 4~6 루프. 완전 정지가 필요하면 4만 홀드. 쓰러지지 않는다. 눈구멍은 원본이 검정이라 「눈 꺼짐」은 넣지 않았다.

## v1 알려진 한계 4건 처리

| v1 한계 | v2 |
|---|---|
| 1. 발밑 회색 잔여 | **해결.** 발바닥 선 아래 전부 삭제 + 바닥 4행에서 몸과 이어지지 않은 조각 삭제(`clean_feet`). 4배 확대 확인 |
| 2. 이동이 핑퐁 | **해결.** 접지/눌림/통과 순환 6프레임, 통과 2장(뒷발 들림 · 앞발 들림) 새로 구성 |
| 3. 예고가 기울임뿐 | **해결.** 팔을 다시 그려 검을 머리 뒤 위로 치켜드는 백스윙 3장 + 시작 1장. 실루엣만으로 「곧 친다」가 보인다. 휘두름 · 접촉 · 회수도 같은 몸에서 만들어 튐이 없다 |
| 4. 팔레트가 A2 마족과 다름 | **미해결(기획 결정).** 팔레트는 v1 24색 유지. 적 유닛 택일 후 재검토 |

## 미정 · 질문

새 질문:
5. **찌르기 셀.** 원본의 찌르기 포즈는 v2b 공격에서 쓰지 않았다. 두 번째 공격 패턴(찌르기)이 필요하면 별도 시트로 만들 수 있다. 필요한가?
6. **팔로우스루 길이.** 8(칼끝 바닥 근처) 1장만 넣었다. 회수가 더 느려야 하면 8~9 사이에 홀드를 넣는다. 히트박스 기준(스프라이트 vs 피벗 오프셋)은 플머 결정 — 위 좌표는 캔버스 기준.

8. 원본 시트의 **달리기 셀**(몸을 앞으로 던지는 자세)은 쓰지 않았다. 적에게 추격 가속 상태가 있으면 6프레임 추가 가능.
