1. **스킬 발동의 팔을 다시 그렸다.** 1차는 폭 2px 선 + 검은 외곽선, 길이 25px로 그려 2등신 비례가 깨지고 막대처럼 보였다. 2차는 원본 팔(폭 5~6px, 어깨~손 9px)에 맞춰 **견갑 7×6 판 + 폭 5px 팔 + 5×5 건틀릿, 어깨~손 11~13px**로 그리고 외곽선은 그림자 쪽에만 둔다. 검은 머리 옆에서 하늘로 치켜드는 위치로 낮췄다(팔이 짧아졌으므로). 발동 중간 프레임 1장을 추가해 10 → **11프레임**.
2. **구르기 시트 추가** `구르기_시트_64x64x8.png`. 전체문서 4장 조작표에 구르기가 없어 **문서 상태는 미정**이다(질문 6).
3. 자체 QA를 자동 검사 + 육안 검사로 다시 돌려 네 시트 모두 95점에 맞췄다(아래 QA 절). 자동 검사 스크립트 `_생성스크립트/qa_knight.py`.

2. **자원 종류별 2포즈?** — 쿨타임형 / 연격 소모형을 한 포즈로 두고 유지 길이만 다르게 할지, 포즈를 나눌지.
3. **낙사 복귀 등장 방식** — 제자리 깜빡임(현재) / 페이드 / 위에서 낙하.
4. **원본 에셋 위치** — `outputs/`(걷기 v4 · 점프 · 피격 · 스킬 v2 · 공격 v3)와 `참고이미지/캐릭터시트_원본.png`. 받으면 기준 프레임을 교체해 다시 뽑는다.
5. 낙사 시 **피해 연출**을 이 시트에 넣을지, 피격 플래시를 앞에 붙일지.
7. **공격 3연격 채택 여부** — 좌클릭 연타를 1 → 2 → 3타로 이어갈지, 기존 옆베기 v3 하나로 갈지. 채택하면 v3와 3연격 중 어느 쪽을 1타로 쓸지(3연격 1타도 가로 베기라 v3와 겹친다).
8. 3연격 참격 이펙트 3종(가로 · 대각 · 내려찍기)은 A4 담당. 기존 옆베기 이펙트는 1타에 그대로 쓸 수 있다.
6. **구르기의 입력과 규칙** — 조작표(WASD · Space · 좌클릭 · 우클릭 · R · 1 · 2)에 없다. 어느 키인지, 무적 시간 유무, 방어(우클릭)와의 관계는 확정이 필요하다. 시트는 만들어 두었다.

## 생성 방법 (재작업용)

`_생성스크립트/kb.py`(공통) · `armlib.py`(검 그리기) · `run.py` · `skill.py` · `fall.py` · `roll.py` · `parts.py`(파츠 분할 + 앞팔 밑 채움) · `rig_combo.py`(파츠 프레임 함수 · 3연격) · `rig_attack.py`(옆베기) · `rig_walk.py`(걷기) · `rig_parry.py`(패링 · 방어)로 생성, `qa_knight.py`로 자동 검사. 기준 프레임 `frames_snap.npy`(걷기 8프레임 64×64×8 RGBA)만 원본 시트로 바꾸고 순서대로 실행하면 같은 규칙으로 다시 나온다. `kb.py`의 `OUT` 경로만 이 폴더로 맞춘다.
