### 1.1 기준점 (실측 · README 2절)

좌표 표기는 `이펙트_정렬표.md`와 같다. **시트 좌표**는 좌상단 (0, 0). **피벗 오프셋**은 피벗(발 중앙)에서 오른쪽 + · 위 +. 판정 · 부착은 피벗 오프셋으로 적는 것을 권장한다(캔버스 크기가 바뀌어도 값이 같다).

| 이름 | 시트 좌표 | 피벗 오프셋 | 쓰는 곳 |
|---|---|---|---|
| 피벗 | (32, 64) · (40, 64) · (48, 80) | (0, 0) | Bottom Center |
| 발바닥 | 64 · 80×64는 y62, 96×80은 y78 | (0, +2) | 발이 피벗보다 2px 위. 주인공과 같다 |
| 머리 중앙 (대기) | (29, 18) | (−3, +46) | 주인공은 x34. 3px 차이 → 질문 3 |
| 가슴 중앙 (대기) | (29, 40) | (−3, +24) | 피격 · 그로기 이펙트 정렬점 |
| **손끝 (하트 참격 4번)** | (60, 41) 80 캔버스 | **(+20, +23)** | 하트 반쪽 궤적 발생점 · 하트 탄 발생점 |
| 머리 중앙 (하트 참격 4번) | (37, 18) | (−3, +46) | |
| 머리 중앙 (마력 고리 4번) | (48, 34) 96×80 | (0, +46) | 고리 · 폭발 이펙트 중심을 잡을 때 |
| 몸 중심 (초안) | — | (0, +30) | 원형 판정의 중심. 연출기획서 「60px 키의 몸 중심 = 발에서 30px 위」 |

주인공 쪽 참고값(전체문서 16장 · 스켈레톤 README): 옆베기 접촉 칼날은 80 캔버스 x54~74 · y31~45 = 피벗 오프셋 **(+14~+34, +19~+33)**. 주인공 가슴은 80 캔버스 (44, 43) = (+4, +21). 바르갈의 참격 사거리를 「주인공 옆베기와 비슷」하게 잡는 근거.

### 1.2 용어

| 용어 | 뜻 |
|---|---|
| 예고 | 공격 판정이 없는 앞 구간. 눈이 밝은 분홍으로 바뀌고 손끝에 하트가 맺힌다(A4). 「손끝에 하트가 뜨면 공격이 온다」 |
| 판정 | 공격 히트박스가 켜진 프레임 |
| 후딜 | 판정이 끝난 뒤 다음 행동으로 못 넘어가는 구간. 안전한 타격 창 |
| 취소 | 주인공 공격에 맞아 경직으로 넘어가며 현재 패턴이 끊기는 것 |
| 단타 | 한 패턴 안에서 주인공에게 한 번만 맞는다. 판정이 2프레임이어도 1회 |

## 2. 상태 기계

```
        ┌──────────────────────────────────────────────┐
        │  대기 ⇄ 걷기 ⇄ 달리기      (이동 · 패턴 선택)  │
        └───────┬──────────────────────────────────────┘
                │ 패턴 선택(8절)
                ▼
   B1-1 · B1-2 · B1-3 · B2-1 · B2-2 · B2-3  ──후딜 끝──▶ 대기(간격 대기)
                │ 주인공 공격 적중(경직 한도 안)
                ▼
             피격(경직) 280ms ──▶ 대기
                
   어느 상태에서든:  HP ≤ 50%(초안) ──▶ 페이즈 전환(무적 1040ms) ──▶ 2페이즈 대기 ──▶ 첫 패턴 = B2-3
   어느 상태에서든:  HP ≤ 10% 또는 R-08 ──▶ 그로기 ──▶ 즉시 승리(D15)
```

| 규칙 | 상태 | 내용 |
|---|---|---|
| 취소 우선순위 | 초안 | 그로기 > 페이즈 전환 > 피격 > 패턴 > 이동. 위가 아래를 끊는다 |
| 경직 | **확정(D8)** | 주인공 공격 적중 시 피격 시트 재생. 진행 중이던 패턴(예고 · 판정 · 후딜)이 **즉시 취소**된다. 켜져 있던 히트박스도 꺼진다 |
| 경직 한도 | **플머** | 무한 경직을 막는 규칙(연속 경직 횟수 · 경직 후 면역 시간 등)은 플머가 정한다. 한도에 걸린 타격은 데미지만 들어가고 패턴은 이어진다 |
| 밀림 | 초안 | 경직 중 넉백 없음. 제자리 |
| 무적 | 초안 | 페이즈 전환 8프레임 전체. 데미지 · 경직 · 그로기 판정 전부 무시. 한 타격으로 50% → 10% 아래까지 떨어지면 전환 대신 그로기(보스문서 2절, 플머) |
| 방향 | 초안 | **예고 1번 프레임에서** 주인공 쪽을 보고 고정. 패턴이 끝날 때까지 방향을 바꾸지 않는다. 주인공이 뒤로 넘어가도 따라 돌지 않는다 |
| 몸통 판정 | 초안 | 바르갈 몸통은 주인공에게 피해를 주지 않는다. 달리기 · 돌진 중에도. 피해는 이펙트 히트박스에만 |
| 피격 판정(맞는 상자) | 초안 | 대기 기준 피벗 오프셋 x −14~+14 · y +2~+60. 모든 시트 공용(캔버스 확장분은 상자에 넣지 않는다). 점프 회피를 위해 y 하한을 발에 붙인다 |
| 패턴 사이 간격 | 초안 | 후딜이 끝난 뒤 대기 **1페이즈 약 1.2초 · 2페이즈 약 0.7초.** 이 사이에는 걷기로 거리 조절만 |
| 연격 | 확정 | 주인공이 바르갈을 때리면 연격이 오른다. 패리 · 가드 성공 시 유지(전체문서 5장). 보스 특례 없음 |

## 8. 패턴 선택 (초안 — 확률 · 세부는 플머)

거리 = 주인공 피벗과 바르갈 피벗의 x 차이(px, 초안값). 무대는 한 화면 폭의 닫힌 공간(보스문서 8절).

| 거리 | 1페이즈 | 2페이즈 |
|---|---|---|
| **사거리 안** ≤ 48 | 하트 참격 → 하트 참격 → 이단 참격 순서를 기본으로 섞는다. **같은 패턴 3연속 금지** | 마력 고리. 고리 N회마다 마력 폭주 1회. 1페이즈 근접 패턴도 섞는다 |
| 근처 48 ~ 96 | 걷기로 접근 | 걷기로 접근, 또는 돌진 참격 |
| 사거리 밖 96 ~ 화면 안 | 달리기로 접근. 접근 전 **하트 탄 1회**를 번갈아 섞는다 | **돌진 참격** |
| 화면 밖 | 하트 탄 반복 | 돌진 참격 반복 |
| 2페이즈 진입 직후 | — | **첫 패턴은 마력 폭주(확정에 준하는 초안)** |

| 규칙 | 내용 |
|---|---|
| 패턴 사이 간격 | 1페이즈 1.2초 · 2페이즈 0.7초. 간격 중에는 걷기 거리 조절만, 공격 안 함 |
| 도발 R-01 | **걸린다.** 대기 · 접근 · 간격을 끊고 즉시 사거리 안 패턴(하트 참격 / 마력 고리)으로. 「나를 친 자만」에서 첫 공격을 부르는 열쇠. 도발 범위는 플머 |
| 등장 직후 | 바르갈이 먼저 움직인다(달려와 공격). 「나를 친 자만」에서 주인공이 기다릴 시간을 짧게 |

## 12. 미정 · 질문

1. **이단 참격 판정 2의 위치** — 설계는 「첫 타를 뒤로 피하면 둘째도 닿지 않는다」(앞쪽 판정)인데, 시트 6번은 4번의 좌우 반전이라 몸이 반대를 보고 손끝이 뒤쪽(−20, +23)에 있다. 선택지: (a) 판정은 앞쪽 유지, 6번을 회전 스미어 프레임으로 손보정 (b) 판정을 몸 중심 좌우 양쪽(±36)으로 바꿔 「회전 베기」로 만들고 설계 문장을 고침 (c) 6번 그림대로 뒤쪽 판정(주인공이 뒤로 넘어간 경우만 맞음). 이 문서는 (a)를 초안으로 썼다.
2. **2페이즈의 예고 신호** — 예고 신호가 「눈이 밝은 분홍」인데 2페이즈는 눈이 상시 분홍이다(README 2절). 2페이즈에서는 예고 구분이 손끝 하트 마크(BV-01)에만 의존한다. BV-01을 필수로 볼지, 2페이즈 눈을 다른 색으로 둘지.
3. **히트박스 기준점** — 머리 중앙 x가 −3(캔버스 중앙 아님). 피격 상자 · 이펙트 정렬을 발(피벗) 기준으로 할지 머리 기준으로 할지. 이 문서는 전부 **피벗 기준**으로 썼다.
4. **돌진 참격 이동 처리** — 4~5번 반복 재생 + 고정 속도(이 문서 초안) vs 거리에 맞춰 속도 가변 + 2프레임 고정. 반복 재생이 그림이 덜 깨진다.
5. **2페이즈 대기** — 페이즈 전환 8번 1장 고정(초안)이면 2페이즈 대기 중 호흡이 없다. 4프레임 시트를 만들지(여유 항목).
6. **보스 그로기 진입 이펙트** — 기존 GROGGY-IN 1개 (0, 0)(초안) vs 연출기획서의 3개 인스턴스 ±24px 시차. 보스 폭이 적과 같으므로 1개로 충분해 보인다.
7. **피격 흰 플래시** — 시트 1번에 박힌 흰색 vs 셰이더. 셰이더면 A3가 플래시 없는 1번을 다시 뽑는다.
8. **페이즈 전환 트리거 HP 50%** — 초안 유지 여부(보스문서 질문 1 승계).
9. **R-08 보스전 최소 연격** — 전체문서 초안 15가 보스전에서 너무 이른지. 보스전만 다른 값을 둘지(보스문서 질문 5 승계).
10. **「나를 친 자만」에서의 끝** — 그로기 즉시 승리(기본안) vs HP 0까지(보스문서 질문 2 승계). 후자면 사망 시트가 필요하다.
11. **마력 고리 · 폭발의 높이** — 「고리는 낮다 → 점프로 피함」을 판정 높이 +4~+30(고리) · +0~+40(폭발)으로 옮겼다. 주인공 점프 높이(플머)와 맞는지.
12. **하트 탄 발생점** — 하트 탄 예고는 「손을 앞으로」라 참격과 포즈가 다르지만 근사 프레임이라 손끝이 같다. (+20, +23)을 그대로 써도 되는지(A3 질문 8 승계).
