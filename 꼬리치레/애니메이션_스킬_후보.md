# 도트 애니메이션용 Claude Code 스킬 후보

> 조사 2026-09-06. 목적: 적·보스·주인공 스프라이트 애니메이션을 더 자연스럽게 만들기 위해 Claude Code 세션에 붙일 스킬.
> 구분 — **지식형**: 애니 원칙·픽셀아트 기법을 Claude에게 가르치는 문서. 외부 프로그램 불필요. **도구형**: 외부 프로그램(Aseprite)이나 이미지 생성 API를 호출.

## 추천 — 바로 받을 것 (지식형, 의존성 없음)

| 순위 | 스킬 | 무엇을 주나 | 설치 | 비고 |
|---|---|---|---|---|
| 1 | **pixel-art** (omer-metin/skills-for-antigravity) | Pedro Medeiros 계열 픽셀아트 기법. 서브픽셀 애니, 디더링, 필로우 셰이딩·AA 오류 지적, 프레임 수보다 품질 우선. 참고 파일(patterns / sharp_edges / validations) 포함 | `npx -y skills add omer-metin/skills-for-antigravity --skill pixel-art --agent claude-code` | 설치 368 · 스타 123. 지금 파이프라인(Python 합성)에 곧바로 적용 가능 |

## 조건부 — 도구가 있으면

| 스킬 | 무엇을 주나 | 조건 | 설치 |
|---|---|---|---|
| **pixel-plugin** (willibrandon) | Aseprite를 자연어로 조작. 프레임 추가·타이밍·태그·링크드 셀·GIF/엔진 내보내기. 하위 스킬 `pixel-art-animator`, `pixel-art-exporter` 포함 | **Aseprite 1.3+ 필요(유료, 약 $20)**. 팀에 Aseprite 사용자가 있으면 가장 강력 | `claude plugin marketplace add willibrandon/pixel-plugin` → `claude plugin install pixel-plugin` |
| **game-character-sprites** (jay6697117/game-skills) | 참고 이미지 기준으로 고정 셀(32/64/128) 애니 시트 생성 → 크로마키 → 검증 → 미리보기까지 파이프라인 | 이미지 생성 백엔드(`codex-gateway-imagegen`) 필요. OpenAI 계열 API 키 | 저장소의 `.claude/skills/game-character-sprites/` 폴더를 `.claude/skills/`에 복사 |
| **ai-pixel-art-image-generation** (ianlintner) | 이미지 생성(OpenAI·Azure·Gemini·fal.ai) + 픽셀화 후처리 + Tiled 내보내기 | API 키 필요 | **이미 설치돼 있음** (이 세션 스킬 목록에 보임). 새 프레임을 생성기로 뽑을 때만 쓴다 |

| pixel-art (inbharatai/claude-skills) | 일반 안내문 수준. 애니 원칙·서브픽셀 등 구체 기법 없음 |
| office-sprite / character-sprite (paulrobello) | 사무실 마스코트용(타이핑·커피). Nano Banana MCP 의존 |
| sprite-sheet (summerengine) | Godot AnimatedSprite2D 연동 전제. 우리는 Unity |

## 적용 순서 제안

1. 1·2·3번을 받는다 (5분, 무료).
2. 적 애니 프롬프트(A2)와 보스 애니 프롬프트(A3)에 한 줄 추가: 「`pixel-art`·`pixel-art-sprites`·`animation-principles:game-development` 스킬을 먼저 읽고, 공격 예고 → 접촉 → 팔로우스루, 피격 스쿼시, 걷기 접지/통과 프레임에 그 원칙을 적용한다.」
3. Aseprite가 있는 팀원이 있으면 pixel-plugin을 그 사람 세션에만 설치해 최종 손보기(서브픽셀 정리, 프레임 타이밍)에 쓴다.
