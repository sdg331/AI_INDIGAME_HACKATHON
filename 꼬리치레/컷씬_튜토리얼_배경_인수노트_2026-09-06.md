## 1. 게임 시작 흐름 (지금 플레이를 누르면)

```
오프닝 컷신 6컷 (클릭으로 대사 넘김, 게임 정지)
      ↓
튜토리얼 맵 (5단계 UI 안내, 맹세 규칙 잠시 해제)
      ↓
적 전원 처리 → 유물 3택(F키) → 다음 스테이지
      ↓
일반 스테이지 3개 → 보스방(바르갈)
      ↓
보스 그로기 → CLEAR 화면 / 맹세 위반·사망 → END 화면
```

문구는 인스펙터(`Oath Line (6컷)`)에서 바꿀 수 있습니다.

## 3. 배경 (원경 · 중경 · 근경 패럴랙스)

`꼬리치레/배경/3 · 2 · 1.png`을 그대로 씁니다. 씬 루트 `ParallaxBackground` 아래 3층입니다.

| 층 | 파일 | 원본 | 스크롤 계수 | z · 정렬 | 비고 |
|---|---|---|---|---|---|
| 원경 하늘 | `BG_Far_Sky` | 배경/3 | 0.05 | 40 · −300 | 노을 구름 |
| 중경 성채 | `BG_Mid_Castle` | 배경/2 | 0.28 | 25 · −200 | 불타는 왕도. 밝기 80% |
| 근경 폐허 | `BG_Near_Ruins` | 배경/1 | 0.55 | 12 · −100 | 돌 폐허. 밝기 62% |

- 세 장 모두 **가로 타일링**(Tiled draw mode, 5장 폭)이라 옆으로 계속 달려도 끊기지 않습니다.
- 중경·근경은 지면 타일과 색이 비슷해 앞뒤가 안 읽혀서 밝기를 낮췄습니다. 인스펙터의 SpriteRenderer Color로 조절하세요.
- **중경 원본(배경/2.png)에는 체커보드가 픽셀로 구워져 있었습니다.** 알파로 복원한 판을 `배경/2_alpha.png`로 남겼고 프로젝트에는 그것이 들어갔습니다. 원본을 다시 넣으면 회색 격자가 그대로 보입니다.
- 카메라의 `ParallaxBackground2D`에 세 층이 연결돼 있습니다. `followCameraVertically`가 켜져 있어 위아래로는 카메라를 그대로 따라가 빈틈이 생기지 않습니다.

## 4. 튜토리얼 맵

| 항목 | 내용 |
|---|---|
| 프리팹 | `Assets/Prefab/Stage/TutorialStage.prefab` |
| 스크립트 | `TutorialDirector` · `TutorialZone` · `TutorialHUD` |
| UI | `Assets/Prefab/UI/TutorialCanvas.prefab` (씬에 배치됨) |
| 지면 | 기존 스테이지와 같은 타일맵. `Assets/Sprite/Tile/1·4.asset`, 셀 1×1, 레이어 Ground, Composite Collider |
| 길이 | 가로 약 94칸. 낙사 구덩이는 없습니다 |
| 연결 | `StageManager`의 `Tutorial Stage Prefab` 슬롯. `Play Tutorial First`를 끄면 건너뜁니다. 일반 스테이지 수에는 포함되지 않습니다 |

### 5개 구역

| # | 위치 x | 안내 | 완료 조건 |
|---|---|---|---|
| 1 | 5 | `A D — 이동` | A 또는 D 입력 |
| 2 | 18 | `Shift — 구르기` | 실제로 구르기가 발동(무적 상태 진입) |
| 3 | 28 | `Space — 점프` | Space 입력. x 32~35에 두 칸 높은 단이 있습니다 |
| 4 | 44 | `좌클릭 — 공격` → `1 또는 2 — 스킬` | 연격 5 달성 후 스킬 1회 사용. 진행 중 `연격 n / 5` 표시 |
| 5 | 57 | `우클릭 — 방어 · 패링` | 패링 성공 1회 |

- 적(고블린)은 x 52에 1마리. 4단계에서는 **무적 + 대기**(때려도 안 죽고 덤비지도 않음), 5단계에서 **보통 적**으로 바뀌어 덤벼듭니다.
- 무적이어도 히트 판정은 성립해 연격이 정상적으로 쌓입니다.
- 튜토리얼이 끝나면 적이 완전히 보통 상태가 되고, 쓰러뜨리면 유물 3택 → 출구(x 86)가 열립니다.
- 튜토리얼 동안에는 **맹세 규칙을 잠시 끕니다.** 안 그러면 「나를 친 자만 친다」에서 허수아비를 먼저 치는 순간 위반이 됩니다. 끝나면 자동으로 다시 켜집니다. (`Suspend Oath During Tutorial` 체크박스)

## 5. 유물 보상과 인벤토리

- 적을 전원 처리하면 출구가 열리면서 **유물 3개가 바닥에 놓입니다.** 가까이 가서 `F`로 하나를 집으면 그 즉시 다음 스테이지로 넘어갑니다.
- 보상 풀은 팀 합의대로 **유물 4종만** 넣었습니다: 밀어내기 · 그로기 가속 · 참격 파동 · 폭발적 무력화. 검은 보상에서 뺐습니다.
- 유물은 실제 에셋 파일이 됐습니다: `Assets/Items/Relic_*.asset`, `Sword_*.asset`. 인스펙터에서 아이콘이나 수치를 바꿀 수 있습니다.
- **스테이지를 넘어가도 유지됩니다.** `StageManager`가 플레이어를 새로 만들지 않고 위치만 옮기기 때문에 인벤토리가 그대로 남습니다.
- 플레이어 프리팹에 `PlayerInventory`와 `RelicSkillController`가 **아예 없었습니다.** 추가했고, 튜토리얼용으로 시작 검에 **참격 파동을 미리 인첸트**해 두었습니다.
- 유물을 새로 얻어도 **검에 끼우는 인첸트 UI는 아직 없습니다.** 스킬로 쓰려면 그 화면이 필요합니다.

## 6. 엔딩 화면

| 상황 | 화면 | 연결 |
|---|---|---|
| 보스 그로기 = 승리 | `CLEAR` (`끝/클리어.png`) | `StageManager.onGameCompleted` |
| 맹세 위반 | `END` (`끝/끝.png`) | `OathSystem.onOathViolated` |
| 플레이어 사망 | `END` | `PlayerHealth.Died` (엔딩 화면이 런타임에 자동 구독) |

- 프리팹 `Assets/Prefab/UI/EndingCanvas.prefab`, 스크립트 `EndingScreen.cs`.
- 검은 화면에서 천천히 밝아지고, 잠깐 뒤 「클릭하면 처음부터 다시 시작합니다」가 뜹니다. 클릭하면 씬을 다시 불러옵니다.
- 문구는 인스펙터에서 바꿀 수 있습니다. 기획의 `YOU DIED` 문구를 쓰려면 `Death Caption`을 고치세요.
- **이걸로 맹세 위반에 결과가 생겼습니다.** 전에는 로그만 찍히고 게임이 계속됐습니다. 다만 기획의 「유물 전부 상실 후 1스테이지 복귀」가 아니라 **씬 재시작**입니다.

## 7. 같이 고친 것

| 문제 | 처리 |
|---|---|
| **씬에 플레이어가 3개** (`Player`, `Player (1)`, 그리고 StageManager가 스폰하는 것) | 씬에 있던 2개를 삭제했습니다. 이게 HP가 0으로 보이고, 카메라가 허공으로 떨어지고, 「선제 공격」 맹세 위반 로그가 뜨던 원인입니다 |
| HP가 0/100으로 표시됨 | HUD 연결이 `Awake`에서 일어나 같은 오브젝트의 `PlayerHealth.Awake`보다 먼저 실행됐습니다. `Start`로 옮겼습니다 |
| 플레이어의 피해 수신 컴포넌트가 비어 있음 | Player 프리팹의 `Damage Receiver Behaviour`에 `PlayerHealth`를 연결했습니다 |
| Build Settings에 없는 `SampleScene` | `TestScene`, `2TestScene`으로 교체했습니다. 엔딩의 다시 시작이 이걸 씁니다 |
| 참격 파동이 흰 네모로 날아감 | 검기 시트(`Sprite/Player/Slash.png`)로 `FX_SlashWave.prefab`을 만들어 연결했습니다 |
| 한글 폰트 | 프로젝트의 `Pretendard-Bold SDF`는 아틀라스가 잘려 글자 대부분이 없었습니다. 동적 폰트 `Pretendard-Bold Dynamic SDF.asset`을 새로 만들어 컷신·튜토리얼·엔딩에 씁니다 |

## 7-2. 추가 반영 (같은 날 오후)

| 항목 | 내용 |
|---|---|
| **공격 히트박스 확대** | Player 프리팹 `Attacck`의 BoxCollider2D를 `1.00 × 1.00` → `1.25 × 1.90`, offset `(0, 0.5)`. 월드 기준 `1.84 × 1.00` → `2.31 × 1.90`. 사거리 2.36 → **2.60**, 세로는 몸 아래쪽만 덮던 것을 **몸 전체(y −0.45~1.45)** 로 맞췄습니다. 스케일(1.84)은 검격 스프라이트에도 걸려 있어 건드리지 않았습니다 |
| **바닥 타일 통일** | 튜토리얼 맵 지면을 `Assets/Sprite/Tile/1.asset` 한 종류로만 다시 깔았습니다(400칸 교체) |
| **배경 무한 루프** | `ParallaxBackground2D`에 가로 되감기를 넣었습니다. 카메라에서 스프라이트 반 장 이상 멀어지면 한 장 폭만큼 되감아 끝이 보이지 않습니다. x=400에서도 세 층 모두 화면을 덮는 것을 확인했습니다. 층마다 `Loop Horizontally` 체크, `Loop Width` 0이면 스프라이트 폭으로 자동 계산 |
| **튜토리얼 고블린 무적 유지** | 5단계 패링에서도, 튜토리얼이 끝난 뒤에도 무적입니다. 대신 튜토리얼을 마치면 `StageManager.ForceUnlockExit()`으로 출구가 열립니다 |

`GameManager`에 `SkillEffects` 컴포넌트를 두고 프리팹을 연결했습니다. 단발 이펙트에는 `EffectAutoDestroy`가 붙어 재생이 끝나면 스스로 사라집니다.

| 이펙트 | 프리팹 | 발동 지점 |

## 8. 남은 것

1. **인첸트 UI** — 얻은 유물을 검에 끼우는 화면. 없으면 첫 유물 말고는 스킬로 쓸 수 없습니다.
2. **맹세 위반 처리 방식** — 지금은 씬 재시작입니다. 기획대로 「유물 상실 + 1스테이지 복귀」로 갈지 정해야 합니다.
3. **낙사** — 튜토리얼 맵에는 구덩이를 넣지 않았습니다. 낙사 복귀 애니(`PlayerFallRecover`)는 클립만 있고 코드가 발동하지 않습니다.
4. **일반 스테이지 레벨 디자인** — 튜토리얼만 새로 만들었습니다. 스테이지 1~5는 기존 `StagePrefab2*` 프리팹을 무작위로 돌리는 상태 그대로입니다.
5. **보스 공격 타이밍** — 클립 판정 프레임(0.32초)과 인스펙터 `telegraphTime`(0.40~0.70초)이 어긋납니다. 앞선 인수 노트 3-1절 참조.
6. **컷신 스킵** — 기획은 스킵 불가라 버튼을 두지 않았습니다. 개발 중 건너뛰려면 `CutsceneController`의 `Play On Start`를 끄세요.
