# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

이 파일은 Claude Code가 이 저장소에서 작업할 때 참고하는 안내서다. 아래 내용은 모두 한글로 작성한다.

## 이 폴더는 무엇인가

코드 저장소가 아니다. 해커톤(주제 「초지일관」) 게임 **「기사의 맹세」(코드명, 제목 미정)** 의 기획·에셋 작업 폴더다.
게임은 Unity 2D 도트 횡스크롤 로그라이크(「스컬」 참고)이며, Unity 프로젝트 자체는 이 폴더에 없다.
빌드·린트·테스트 명령은 없다. 산출물은 마크다운/HTML 문서와 스프라이트 시트·미리보기 GIF다.

## 문서 상태 표기 규칙 (반드시 지킬 것)

전체문서 0장에 정의된 여섯 가지 상태를 그대로 따른다.

| 표기 | 의미 | 취급 |
|---|---|---|
| **확정** | 팀이 합의한 것 | 이것만 작업 근거로 삼는다 |
| **미정** | 정해지지 않은 것 | 내용을 지어내지 않고 **비워 둔다** |
| **초안** | 출발값 수치 | 확정 아님. 그대로 쓰되 "초안"임을 표기 |
| **플머** | 프로그래머가 구현 중 정함 | 기획에서 값을 주지 않는다 (패리 판정 시간, 추적 해제 거리·시간, 근접 유닛 행동·수치) |
| **별도 문서** | 따로 만드는 문서 | 이 문서에서 다루지 않음 |
| **제안 보관함** | 미채택 아이디어 | 기획이 아니다. 확정처럼 쓰지 않는다 |

핵심 원칙: **확정된 것만 담는다.** 1차 허브는 지어낸 내용이 섞여 폐기된 이력이 있다. 빈 자리를 그럴싸한 내용으로 채우지 말 것.

현재 미정 2건: **세 번째 맹세**(시연 기준 3종 필요), **게임 제목**. UI에 세 번째 맹세 자리는 **문장 없이 슬롯만** 둔다.

## 다음 작업: 별도 문서 5건

권장 순서와 담당은 전체문서 15장 참조. 클로드 코드에서 만들기로 한 첫 문서는 **UI 목업 리스트**다.

- **UI 목업 리스트** (클로드 코드 담당, 플머 급함) — 맹세 문장 · 체력 · 연격(화면 상단) · 검 슬롯 2칸 · 유물 슬롯 · **유물 3택 선택 화면** · 인벤토리(검에 인첸트) · YOU DIED.
  근거 장: 4장(조작) · 5장(연격 상단 표시, YOU DIED) · 6장(검 2자루) · 7장(유물 3택, 10개 목록) · 8장(인첸트 검당 2개, 여분 3개).
- 레벨 디자인 문서 → 보스 문서(바르갈 2페이즈) → 연출 기획서(오프닝 6컷) → BGM·사운드 목록.

## 게임 규칙 요약 (문서를 열기 전 알아둘 것)

- 맹세는 런마다 바뀌고 검을 바꿔도 유지된다. 위반 = 즉시 게임 오버(`YOU DIED`), 유물 전부 상실, 1스테이지 복귀. 영구 성장 없음.
- 확정 맹세 2종: 「나는 죽이지 못한다」(HP 10% 이하 = 그로기 = 멈춤 = 무력화, 적 낙사시키면 위반) · 「나는 나를 친 자만 친다」.
- 검은 한 종류, 성능 차이 없음. 손 1 + 예비 1(3스테이지 획득). 스왑 쿨타임 5초, 스왑은 스킬 발동이 아니다. 스킬 키는 R.
- 유물 10개 동급, 검당 인첸트 2개, 여분 보관 3개(최대 소지 7). 첫 유물은 **도발** 고정. 스킬은 유물로만 얻는다. 인첸트는 비전투 상황에서만.
- 스킬 자원은 두 갈래: 쿨타임 / 연격 소모(정량 또는 전량). 연격은 5초 유지, 상한 없음, 방어·패리 성공 시 유지.
- 스테이지 5개 고정 배치, 클리어 조건은 적 전원 무력화, 보상은 유물 3택.
- 조작: WASD · Space · 좌클릭 공격 · 우클릭 방어(패리 피해 0 / 가드 80% 감소) · R 스킬 · 1·2 검 스왑.

## 아트 · Unity 임포트 규약

- 아트 방향: 2등신 치비, 따뜻하고 부드러운 중세 판타지. 스컬 톤은 **폐기됨**.
- 캐릭터 기준 **64×64**, 키 60px. 공격·스킬만 캔버스가 넓다(80×64, 96×80).
- 모든 시트 **Pivot = Bottom Center.** 이펙트 시트는 캐릭터와 **같은 Pixels Per Unit.**
- 옆베기 이펙트 정렬: 이펙트 (30, 34) 지점을 캐릭터 가슴(80 캔버스 기준 x 44, y 43)에.
- 미리보기 GIF의 재생 속도는 임시값. 실제 프레임 시간은 플머가 잡는다.
