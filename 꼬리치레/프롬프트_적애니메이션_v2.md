규격 (확정, v1과 동일)
- 64×64, 키 58px, Pivot = Bottom Center, 발바닥 y=62. 공격만 80×64(x=40이 몸 중심).
- 오른쪽을 본다. 주인공과 같은 Pixels Per Unit. 24색 이내 공통 팔레트, 안티에일리어싱 없음, 투명 배경.
- 파일명: `스켈레톤_대기_시트_64x64x4.png` 식으로 v1과 같은 규칙. 프레임 수는 바꿔도 된다.

만들 것 — v1 한계를 고치는 순서대로
1. **이동 → 진짜 걷기 사이클.** v1은 원본 1~4를 핑퐁했다. 원본 1~4 중 접지 · 통과 프레임을 골라 배치하고, 반대쪽 발이 앞으로 나오는 프레임 2장을 **픽셀 단위로 직접 그려** 6~8프레임 순환으로 만든다. 상체는 고정, 다리 접지/눌림/교차/상승, 어깨축 팔 회전, 머리 1px 바운스 — 주인공 걷기 v4 방식(전체문서 16장)을 따른다. 방패는 항상 앞(오른쪽)에 있어야 한다.

5. 대기 · 피격은 v1을 그대로 가져온다. 필요하면 1px 단위로만 손본다.

4. `적 2.png` — 원본 시트. 공격 셀에 흰 참격 호가 그려져 있고 스크립트가 이를 지운다. 달리기 셀(몸을 앞으로 던지는 포즈)은 v1에서 쓰지 않았다.
5. `미리보기_걷기8.gif`, `content.png` — 밀도 · 톤 기준.

규격 (확정, v1과 동일)
- 64×64, 키 58px, Pivot = Bottom Center, 발바닥 y=62. 공격만 80×64(x=40이 몸 중심).
- 오른쪽을 본다. 주인공과 같은 Pixels Per Unit. 24색 이내 공통 팔레트(`outputs/적_고블린_v1/_build.json`), 안티에일리어싱 없음, 투명 배경.
- 파일명은 v1 규칙. 프레임 수는 바꿔도 된다.

만들 것 — v1 한계를 고치는 순서대로
1. **이동 → 진짜 걷기 사이클.** v1의 원본 8프레임은 다리 차이가 1~2px라 제자리 떨림에 가깝다. 원본 1프레임을 기준 포즈로 잡고, 다리 접지 · 눌림 · 교차 · 상승 4단계 × 좌우 = 6~8프레임을 **픽셀 단위로 직접 그린다.** 상체 고정, 어깨축 팔 회전, 큰 귀가 1px 늦게 따라오는 팔로우스루, 머리 1px 바운스. 주인공 걷기 v4 방식(전체문서 16장)을 따른다.
2. **공격 예고 → 실제 백스윙 포즈.** 단검을 뒤로 빼고 몸을 웅크리는 예고 프레임을 직접 그려 3·4·5에 넣는다. 원본 공격 셀은 낮게 파고들며 베는 자세라, 예고에서 「웅크림 → 튀어나감」의 스쿼시&스트레치가 자연스럽다. 팔로우스루 1장 추가.
3. **참격 호 흔적 완전 제거.** 접촉 프레임 칼끝 주변에 원본 참격 호의 크림색 픽셀이 1~2px 남을 수 있다. 4배 확대로 확인하고 픽셀 단위로 지운다. 칼날은 남긴다.
4. **그로기 멈춤 포즈 강화.** 무릎 굽힘 + 고개 숙임 + 단검 든 손이 늘어지는 포즈를 직접 그려 4번 프레임으로 쓴다. 쓰러지지 않는다. 붉은 눈이 꺼지는 표현은 팔레트 24색 안에서 눈 색을 1색 확보할 수 있으면 넣고, 아니면 넣지 않는다.
5. **달리기(추격) 시트 — 조건부.** 원본 달리기 셀을 써서 `고블린_달리기_시트_64x64x6.png`를 만들 수 있다. 하지만 적에게 달리기 상태가 있는지는 플머가 정하지 않았다. **만들지 말고** README 질문에 「달리기 셀이 있으니 필요하면 6프레임 추가 가능」이라고만 적는다.
6. 대기 · 피격은 v1을 그대로 가져온다.

방법
- 스크립트 기반으로 하되, 새로 그리는 프레임은 v1 프레임 PNG의 픽셀 배열을 직접 편집(numpy)해서 만든다. 외부 이미지 생성기는 쓰지 않는다.
- 프레임을 만들 때마다 4배 GIF로 재생해 게임 속도에서 확인한다.
- 팔레트는 v1의 24색을 그대로. 새 색은 그로기 눈 1색까지만 허용.

README.md에 적을 것
