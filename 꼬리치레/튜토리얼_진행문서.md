## 0. 이 문서의 규칙과 근거

전체문서 0장의 상태 표기를 그대로 쓴다. **확정** · **미정** · **초안** · **플머** · **별도 문서** · **제안 보관함**.
표기가 없는 서술은 모두 **초안**이다. UI 안내 문구는 전부 초안이며 바꿔도 된다. 바꾸면 안 되는 것은 **가르치는 순서와 완료 조건**이다.

## 1. 개요

### 목적
플레이어가 1스테이지에 들어가기 전에 **일곱 가지**를 손으로 한 번씩 해 보게 한다. 설명은 읽는 것이 아니라 하는 것으로 끝낸다. 각 단계는 플레이어가 그 입력을 실제로 성공해야 넘어간다.

### 가르치는 것 · 순서
| 순서 | 배우는 것 | 입력 | 적 상태 |
|---|---|---|---|
| 1 | 이동 · 구르기 · 점프 | A D · Shift · Space | 없음 |
| 2 | 공격 | 좌클릭 | 대기 (가만히 서 있음) |
| 3 | 연격 쌓기 | 좌클릭 ×5 | **무적** · 대기 |
| 4 | 스킬 발동 | R | 무적 · 대기 |
| 5 | 방어 (가드) | 우클릭 | **공격 반복** |
| 6 | 패리, 그리고 가드와의 차이 | 우클릭(타이밍) | 공격 반복 |
| 7 | 스테이지 클리어 | — | (질문 Q6) |

### 흐름 한 줄
빈 길을 걷고 → 서 있는 적을 베고 → 다섯 번 베어 연격을 만들고 → R로 궤적을 날리고 → 적에게 다가가 공격을 막고 → 같은 공격을 패리로 튕기고 → 클리어.

### 위치 · 반복 여부
**미정** — 튜토리얼이 런의 어디에 붙는지(오프닝 컷신 뒤·1스테이지 앞인지, 첫 런에만 나오는지, 건너뛸 수 있는지)는 정해지지 않았다. 질문 Q3.

## 2. 단계별 진행

각 단계는 같은 틀로 적는다. **목표 · 화면 · 적 · 완료 조건 · 넘어감 · 근거.** 안내 문구는 3장의 ID로 가리킨다.

### 단계 1 — 이동
| 항목 | 내용 |
|---|---|
| 목표 | A·D 이동, Shift 구르기, Space 점프를 한 번씩 해 본다 |
| 화면 | 시작 지점에 T-01(이동) → T-02(구르기) → T-03(점프)이 차례로 뜬다. 세 입력이 한 번에 나오지 않고, 하나를 해내면 다음 문구가 뜬다 |
| 적 | 없다 |
| 완료 조건 | 세 입력을 각각 1회 이상 수행 |
| 넘어감 | 완료 후 앞으로 걸어가면 단계 2의 적이 보이는 지점에 닿는다 |
| 근거 | 조작 4장(확정). **Shift 구르기는 확정 아님 → Q1** |

- 이동 문구는 A·D만 적는다. W·S는 횡스크롤에서 쓸 곳이 없으므로 튜토리얼에서 언급하지 않는다(초안).
- 점프를 가르치는 자리에 작은 단차를 하나 두면 좋다. 낙사 지형은 튜토리얼에 **넣지 않는다**(초안 · 낙사 = 맹세 위반 경로이므로 가르치기 전에 노출하지 않는다).

### 단계 2 — 공격
| 항목 | 내용 |
|---|---|
| 목표 | 좌클릭으로 적을 한 번 벤다 |
| 화면 | 적이 화면에 들어오면 T-04(공격). 적 머리 위에 표식(초안) |
| 적 | **대기.** 가만히 서 있고 반격하지 않는다. 플레이어를 추적하지 않는다 |
| 완료 조건 | 공격 1회 적중 |
| 넘어감 | 적중 즉시 단계 3 문구로 바뀐다 |
| 근거 | 조작 4장(확정) |

- 이 단계의 적은 **HP가 깎여도 되는가** — 다음 단계에서 곧바로 무적이 되므로 1타로는 그로기에 들어가지 않게만 하면 된다(플머).
- 「나는 나를 친 자만 친다」 맹세가 걸려 있으면 이 행동이 위반이다 → **Q4 (튜토리얼에 맹세를 적용하는가)**

### 단계 3 — 연격 쌓기
| 항목 | 내용 |
|---|---|
| 목표 | 적을 **5번** 연속으로 때려 상단 연격 카운터를 5까지 올린다 |
| 화면 | T-05(연격). 상단 연격 카운터를 화살표·강조로 가리킨다. 카운터가 오를 때마다 문구의 숫자가 갱신된다(「연격 3 / 5」 초안) |
| 적 | **무적.** HP가 깎이지 않는다. 대기. 반격하지 않는다 |
| 완료 조건 | 연격 카운터 **≥ 5** |
| 넘어감 | 5에 닿는 순간 단계 4 문구(T-06)로 바뀐다 |
| 근거 | 연격 5장(확정). 5는 참격 파동 소모량(7장 초안)과 같은 값 |

- **무적이어도 히트 판정은 성립**해야 한다. 연격은 「맞은 횟수」이므로 피해 0이어도 카운터가 올라야 한다(플머).
- 연격은 5초가 지나면 초기화된다(확정). 튜토리얼에서도 그대로 둔다. 초기화되면 문구는 그대로 두고 카운터만 0에서 다시 오르게 한다(초안). 여기서 「5초 안에 이어서 때려야 한다」는 것을 몸으로 배운다.
- 5라는 숫자는 참격 파동 소모량에 **묶여 있다.** 소모량이 바뀌면 이 단계의 목표치도 같이 바뀐다(플머 상수 하나로).

### 단계 4 — 스킬 발동
| 항목 | 내용 |
|---|---|
| 목표 | R로 참격 파동을 쓴다 |
| 화면 | 연격 5 달성 시 T-06(스킬 준비) → T-07(발동). 검 슬롯의 참격 파동 아이콘과 R 키를 가리킨다 |
| 적 | 무적 · 대기 (단계 3과 동일) |
| 완료 조건 | 참격 파동 발동 1회. 궤적이 적에게 맞을 필요는 없다(초안) |
| 넘어감 | 발동 후 연격이 5 소모되어 0이 된 것을 짧게 보여준 뒤 단계 5로 |
| 근거 | 스킬 키 R · 유물로만 스킬(7장 확정) · 참격 파동 연격 정량 5 소모(초안) |

- 튜토리얼 검에는 **참격 파동이 미리 인첸트되어 있다**(이번 결정). 플레이어가 인벤토리를 열거나 인첸트를 하지는 않는다. 인첸트는 튜토리얼에서 가르치지 않는다.
- T-06 문구에 「연격을 써서 발동하는 스킬」임을 한 줄 넣는다. 쿨타임 스킬과의 구분은 여기서 다루지 않는다(첫 유물 도발이 그 역할, 7장 확정).
- 참격 파동을 미리 끼워 두는 것과 「첫 유물 = 도발 고정」의 관계 → **Q2**

### 단계 5 — 방어 (가드)
| 항목 | 내용 |
|---|---|
| 목표 | 적의 공격을 우클릭으로 막는다 |
| 화면 | T-08(다가가라) → 적이 사거리에 들어오면 T-09(방어) |
| 적 | 무적 해제 여부는 무관(계속 무적이어도 됨, 초안). **플레이어가 다가오면 공격 모션을 반복한다.** 이동·추적하지 않고 제자리에서 휘두른다 |
| 완료 조건 | 방어 성공 1회(패리든 가드든) |
| 넘어감 | 성공 즉시 단계 6 문구로 |
| 근거 | 방어 5장(확정) |

- 적의 공격 반복 간격은 **플머.** 다만 플레이어가 우클릭을 누른 채로 기다리면 반드시 한 번은 맞아 주도록 간격이 짧아야 한다(초안: 2초 안팎).
- 이 단계에서 우연히 패리가 나올 수 있다. 그래도 완료로 친다. 차이는 단계 6에서 가르친다.
- 적의 공격이 플레이어 HP를 깎는가 → **Q5**

### 단계 6 — 패리, 그리고 가드와의 차이
| 항목 | 내용 |
|---|---|
| 목표 | 같은 공격을 **패리**로 막고, 패리와 가드의 차이를 안다 |
| 화면 | T-10(패리 해 보라) → 패리 성공 시 T-11(차이 설명) |
| 적 | 단계 5와 동일. 공격 반복 |
| 완료 조건 | **패리** 판정으로 방어 성공 1회 |
| 넘어감 | T-11을 읽을 시간을 준 뒤(초안 3초, 또는 아무 키) 단계 7로 |
| 근거 | 패리 피해 0 · 가드 80% 감소(5장 확정). 판정 시간은 플머 |

- T-10에는 「적이 휘두르는 순간에 맞춰 우클릭」 정도로만 쓴다. 정확한 프레임·시간은 플머가 정하므로 문구에 숫자를 넣지 않는다.
- T-11이 가르쳐야 하는 문장은 두 개뿐이다. **패리 = 완전 방어(피해 0)** · **가드 = 피해 80% 감소.** 둘 다 연격은 유지된다는 말은 넣어도 되고 빼도 된다(초안: 넣는다).
- 패리 성공 시 이펙트·짧은 정지 같은 연출은 **별도 문서**(연출 기획서).

### 단계 7 — 클리어
| 항목 | 내용 |
|---|---|
| 목표 | 튜토리얼 스테이지를 끝낸다 |
| 화면 | T-12(클리어) |
| 적 | **Q6** |
| 완료 조건 | Q6에 따름 |
| 넘어감 | 1스테이지(또는 오프닝 컷신, Q3) |
| 근거 | 클리어 조건 = 적 전원 무력화(9장 확정) |

- 클리어 조건이 「적 전원 무력화」이므로 원칙대로라면 패리 뒤에 적의 무적이 풀리고, 플레이어가 그로기까지 때려서 끝나야 한다. 이 마지막 구간을 넣을지, 아니면 패리 성공 즉시 클리어로 처리할지는 정해지지 않았다 → **Q6.** 문서는 **넣는 쪽(초안)** 으로 적어 두되 표시는 남긴다.
- 클리어 보상(유물 3택)이 튜토리얼에도 나오는가 → **Q7**

## 3. UI 안내 문구 목록 (초안 · 플머 · UI용)

전부 초안이다. 표시 위치는 화면 중앙 상단 한 줄을 기본으로 하고(초안), 키 이름은 키캡 아이콘으로 바꿔도 된다. 사라지는 조건은 「완료 조건 충족」이 기본이다.

| ID | 단계 | 뜨는 시점 | 문구 (초안) | 가리키는 UI |
|---|---|---|---|---|
| T-01 | 1 | 시작 | `A · D  이동` | — |
| T-02 | 1 | T-01 완료 | `Shift  구르기` | — |
| T-03 | 1 | T-02 완료 | `Space  점프` | — |
| T-04 | 2 | 적이 화면에 들어옴 | `좌클릭  공격 — 적을 베어라` | 적 머리 위 표식 |
| T-05 | 3 | T-04 완료 | `연속으로 때려 연격을 쌓아라   연격 n / 5` | 상단 연격 카운터 |
| T-06 | 4 | 연격 5 | `연격 5 달성 — 참격 파동을 쓸 수 있다` | 검 슬롯 · 참격 파동 아이콘 |
| T-07 | 4 | T-06 직후 | `R  스킬 발동` | R 키 |
| T-08 | 5 | T-07 완료 | `적에게 다가가라` | 적 |
| T-09 | 5 | 적이 공격 모션 시작 | `우클릭  방어` | — |
| T-10 | 6 | T-09 완료 | `적이 휘두르는 순간에 맞춰 우클릭 — 패리` | — |
| T-11 | 6 | 패리 성공 | `패리 — 완전 방어, 피해 0` / `방어 — 피해 80% 감소` | 체력 바 |
| T-12 | 7 | 클리어 | `튜토리얼 완료` (Q6·Q7에 따라 달라짐) | — |

- T-05의 `n`은 현재 연격 값. 5초 초기화로 0이 되면 `0 / 5`로 돌아간다.
- T-11은 두 줄이며, 두 줄이 **대비**되게 놓는다(패리 위 · 방어 아래, 또는 좌우). 연격 유지 문장을 넣는다면 세 번째 줄: `둘 다 연격은 유지된다`.
- T-06 · T-07은 합쳐서 한 문구로 만들어도 된다.

## 4. 튜토리얼 적 사양 (플머)

근접 유닛 1마리를 쓴다. 외형·애니는 본편 근접 유닛과 같다. 행동만 단계별로 고정한다.

| 단계 | 추적 | 반격 | 피해 받음 | 공격 |
|---|---|---|---|---|
| 2 공격 | 안 함 | 안 함 | 받음(그로기 진입은 막을 것) | 안 함 |
| 3 연격 · 4 스킬 | 안 함 | 안 함 | **무적** (히트 판정은 성립, HP 불변) | 안 함 |
| 5 방어 · 6 패리 | 안 함 | — | 무관(초안: 무적 유지) | **제자리에서 반복.** 플레이어가 사거리에 들어오면 시작 |
| 7 클리어 | Q6 | Q6 | Q6 | Q6 |

- 단계 3의 무적은 「피해 0」이지 「히트 무시」가 아니다. 연격 카운터가 올라야 하고, 피격 애니·이펙트는 나와야 한다.
- 단계 5·6의 공격은 예고 동작이 눈에 보이는 것이어야 한다. 패리 타이밍을 배우는 자리이기 때문이다. 근접 유닛의 공격 애니 중 예고가 긴 것을 쓴다(플머·아트).
- 튜토리얼 적이 「전투 상황」을 발생시키는가(추적 판정)는 무관하다. 튜토리얼에서 인첸트를 열지 않기 때문이다.
