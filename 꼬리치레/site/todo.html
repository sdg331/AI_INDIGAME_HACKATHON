1. 미정 — 기획이 결정해야 할 것

항목 급함 메모
세 번째 맹세 보통 시연 기준 3종 필요. 후보 넷은 제안 보관함에 있음 (물러서지 않는다 · 등을 보인 자를 치지 않는다 · 한 번 벤 자를 다시 베지 않는다 · 검을 손에서 놓지 않는다)
게임 제목 낮음 코드명 「기사의 맹세」로 쓰는 중
맹세를 지킬 때의 보상 — "따로 두지 않는 방향"이나 확정 아님
유물 수치 — 허브에는 쿨타임 · 소모량 · 효과량 "모두 미정"으로 표기. 초안 표는 있으나 플레이 테스트 조정 전
바르갈 체력 · 수치 — 미정
인벤토리 화면 구성 — 미정. UI 목업 리스트로 넘어감
스테이지 1~5 개별 내용 — 카드 5장 전부 "무대 · 적 배치 · 길이 · 가르치는 것 — 모두 미정"

2. 별도 문서 — 작성 예정 5건

허브 기준 권장 순서: UI 목업 리스트 → 레벨 디자인 → 보스.

5 BGM · 사운드 목록 필요한 곡과 효과음 목록 사운드

3. 플머가 정할 것 — 3건

기획에서 값을 주지 않는다. 프로그래머가 구현하면서 잡는다.

  • [ ] 패리 판정 시간 — 방어 입력 후 몇 초 · 몇 프레임 안에 성공해야 패리인지
  • [ ] 추적 해제 거리 · 시간 — 적이 플레이어를 놓치는 조건
  • [ ] 근접 유닛 행동 · 수치 — 공격 방식, 체력, 데미지, 이동 속도

6. 허브 문서 자체의 정리 필요 사항

허브 v4 안에서 서로 어긋나는 부분. 다음 갱신 때 맞춘다.

  • [ ] 플머 Q&A에 "두 번째 검 획득 스테이지 미정", "스킬 입력 키 미정", "추적 해제 조건 미정"이 남아 있다. 같은 문서의 표에서는 3스테이지 · R · 플머로 확정되어 있다. 오래된 답변이다.
  • [ ] 스테이지 표의 클리어 보상이 "유물 1개"인데 유물 규칙 표에서는 "3개 중 하나 선택"이다.
  • [ ] 스킬 자원 절에서 유물 수치를 "모두 미정"이라 했지만 바로 아래에 초안 표가 있다. "초안" 표기로 통일한다.
  • [ ] 상단 숫자 카드의 미정 개수가 "–"로 비어 있다. (현재 미정 표 기준 2건)
