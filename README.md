## 📌 프로젝트 소개 (About)
본 프로젝트는 **AI Indie Game Hackathon**에 출품하기 위해 제작된 인디게임입니다. Unity 엔진을 기반으로 개발되고 있으며, 플레이어 액션 확장 및 다양한 보스 패턴 구현을 포함하고 있습니다.

- **커뮤니티 & 소통**: 프로젝트 참여 및 문의 사항은 [Discord 서버](https://discord.gg/UJkssVu3G)를 통해 공유됩니다.

---

## 🛠 Tech Stack

- **Engine & Language**: Unity (C#), ShaderLab, HLSL
- **AI & Scripts**: Python
- **Collaboration**: GitHub, Discord
